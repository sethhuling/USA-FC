What this means
The hit rate is how often a request was answered from the server's memory instead of calling API-Football — higher is better. Counters reset whenever the server restarts (Render restarts it on every deploy, and free-tier sleep also restarts it). A big 24-hour number right after a deploy is normal: the startup cache warm uses about 1,400 requests.
